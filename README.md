# Kehinde Onilamo — Teaching Portfolio

A single-page portfolio and credentials site for **Onilamo Kehinde Olubunmi**, a PGDE-qualified teacher and former Head Mistress based in Abuja, Nigeria.

**Live site:** https://favour187.github.io/kehinde-onilamo/

## Contents
- Profile and subjects taught — Basic Technology, Technical Drawing, Computer Studies
- Career history and qualifications
- A PDF-style viewer presenting nine original documents (PGDE notification, HND, ND, NYSC, NABTEB, curriculum vitae, referees)
- Referees and contact details, including WhatsApp and a print-ready CV layout

## Technical notes
- One self-contained `index.html`. All images are embedded as base64, so there are no external requests and no dependencies.
- No frameworks, no build step, no tracking. Works offline and prints cleanly.
- Fully responsive, keyboard accessible, and respects reduced-motion preferences.
